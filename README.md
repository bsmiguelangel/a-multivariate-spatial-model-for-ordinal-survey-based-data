# A multivariate spatial model for ordinal survey-based data

Paper under review: https://arxiv.org/abs/2507.20944

This repository contains the `R` code used to run the full case study. The implementation is based on the `NIMBLE` Bayesian inference MCMC package. The result files (posterior samples) from the models are not included, as they exceed 25MB; however, `Google Drive` links are provided for downloading them.

**Note**: Due to the individual nature of the dataset used, we are not allowed to share it. However, data providers may grant access to the dataset under the same conditions as the authors of this study. To allow readers to run the code and obtain results similar to those reported in the paper, we also provide a synthetic dataset with characteristics similar to those of the original data.
