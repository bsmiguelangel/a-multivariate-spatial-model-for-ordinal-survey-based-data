# A multivariate spatial model for ordinal survey-based data

Paper under review: https://arxiv.org/abs/2507.20944

This repository contains the `R` code used to reproduce the full case study. The implementation is based on the `NIMBLE` Bayesian inference MCMC package.

**Note**: Due to confidentiality restrictions, the original survey data cannot be publicly shared. However, the data providers may grant access to the dataset under the same conditions as those granted to the authors of this study. To allow readers without access to the original data to run the code and obtain results similar to those reported in the paper, we also provide a synthetic dataset with characteristics similar to those of the original data.
